## Key Features
* **Online Multiplayer:** Real-time multiplayer architecture implemented using Unity Netcode.
* **Unique Abilities:** Each player has distinct mechanics to solve challenges cooperatively.

---

## Technical Stack
* **Language:** C#
* **Engine:** Unity
* **Networking:** Unity Netcode for GameObjects (NGO)

---

## How to Play

### Controls

**General:**
- `ESC`: Open/Close Menu

**Player 1 (Melee):**
- `Arrow Keys`: Move
- `Space`: Melee Attack

**Player 2 (Shooter):**
- `WASD`: Move
- `E`: Shoot
